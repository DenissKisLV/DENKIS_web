# Slideshow & Project Pages / Pictures

Upload any pictures, project drawing sheets, or blueprints you want to showcase here!

### How it works:
- Every image placed in this folder (`src/assets/slideshow/`) is **automatically loaded** into the rotating fade-in / fade-out slideshow on the right side of the page (and below the text on mobile).
- Images rotate slowly one after another with a smooth fade effect.
- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp` (case-insensitive).
- **Tip for ordering:** Name files with numbers at the beginning if you want a specific order (e.g. `01_project_drawing.jpg`, `02_blueprint.png`, `03_site.jpg`).
